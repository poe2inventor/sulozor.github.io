# Файлы перевода

В этой директории находятся файлы перевода в формате JSON для планировщика храмов PoE2.

## Важно: Сопоставление с учетом регистра

**Все переводы строго следуют правилам сопоставления с учетом регистра.**

- "Path" и "path" рассматриваются как разные строки
- Переводятся только точные совпадения по регистру
- Это сделано намеренно, чтобы предотвратить некорректные переводы
- Регулярное выражение проверяется во время выполнения, чтобы убедиться в отсутствии флага нечувствительности к регистру

## Структура файлов

- **temple-rooms.json** - Названия храмовых комнат (32 записи)

- Содержит переводы для всех типов храмовых комнат

- Примеры: Путь, Гарнизон, Командир, Сокровищница, Чудотворец и т. д.

- **medallions.json** - Названия медальонов (10 записей)

- Содержит переводы для всех типов медальонов

- Примеры: Медальон Джуаталотли, Медальон Хайокси и т. д.

- **ui-terms.json** - Термины пользовательского интерфейса и общие строки (39 записей)

- Содержит переводы для элементов пользовательского интерфейса, кнопок, меток

- Примеры: Монстр, Активные бонусы, Как использовать и т. д.

- **modifiers.json** - Модификаторы монстров/сундуков/эффектов (99 записей)

- Содержит переводы игровых модификаторов и эффектов

- Примеры: "Увеличено на 10% количество наборов монстров", "Увеличена на 15% эффективность редких монстров" и т. д.

## Добавление новых переводов

Чтобы добавить новые переводы:

1. Выберите соответствующий JSON-файл в зависимости от категории
2. Добавьте английскую строку в качестве ключа и китайский перевод в качестве значения
3. **ВАЖНО**: Убедитесь, что английский ключ точно соответствует регистру, используемому в приложении
4. Убедитесь в правильном форматировании JSON (используйте запятые между записями, не добавляйте запятую в конце последней записи)
5. Проверьте, загрузив страницу и проверив консоль на общее количество загруженных переводов

**Примечание о чувствительности к регистру**: Ключи переводов чувствительны к регистру. "Path", "path" и "PATH" будут рассматриваться как три разных ключа перевода.

## Формат JSON

```json
{
"Russian String": "Poe-Inventor",
"Another String": "另一个翻译"
}
```

## Как это работает

Файл `translator.js` загружает все эти JSON-файлы во время выполнения с помощью `fetch()`, объединяет их в один объект перевода и применяет переводы к содержимому страницы с помощью MutationObserver для обработки динамического контента.
